# Library_-Management_System
“A structured Library Management System using SQL that handles book inventory, member management, and transaction tracking. Includes ER diagram, database schema, and optimized queries.”

##  Features
-  Manage book details
-  Manage member information
-  Issue and return books
-  View records using SQL queries
-  Maintain relationships using foreign keys

## Technologies Used
- SQL (Oracle)
- ER Diagram (dbdiagram.io / draw.io)
